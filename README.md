# テニス ダブルス ローテーション表ジェネレーター 🎾

テニスのダブルス試合のローテーション表を自動生成する Web アプリです。高度な公平性アルゴリズムにより、出場回数・対戦相手・ペア組みを最適化します。

## ✨ 特徴

- 🎨 可愛いパステルデザイン + Nekos.best API 背景画像
- 📱 スマホ対応（iPhone 11 検証済み）
- ⚖️ **高度な公平性アルゴリズム**
  - 段階的プレイヤー選択（主役 → 対戦主役 → ペア）
  - 動的パターン評価による最適マッチング
  - 出場回数・対戦履歴・ペア履歴を総合評価
  - 少人数（4 名）でも動作する柔軟なロジック
- 🎯 複数コート対応（1 ～ 3 コート）
- 📊 統計表示機能（出場回数・ペア回数・対戦回数）
- 💾 PNG 画像保存
- 🔍 デバッグログ出力（開発者ツールで確認可能）
- 🔒 完全クライアントサイド実行（データ送信なし）

## 🧮 公平性アルゴリズム

### ローテーション生成ロジック

**ステップ 1: 主役プレイヤー選択**

- コート数分の主役プレイヤーを出場回数の少ない順に選択

**ステップ 2: 対戦主役プレイヤー選択**

- 各コートの対戦主役を選択
- 2^コート数 通りの組み合わせパターンを評価
- 評価基準: 対戦履歴（10 点）+ ペア履歴（50 点）
- 最も履歴が少ないパターンを選択

**ステップ 3: ペアプレイヤー選択**

1. 残りプレイヤー数に応じて各主役に割り当てるペア候補数を決定
   - 通常: 各主役に 2 名（計 4 名）
   - 少人数（4 名など）: 各主役に 1 名（計 2 名）
   - 計算式: `Math.min(2, Math.floor(残りプレイヤー数 / 2))`
2. 各主役のペア候補を選択
   - 評価: ペア履歴 50 点 + 対戦履歴 5 点 + 出場回数 10 点 + プレイヤー番号 0.01 点
3. パターン評価
   - 2 名 ×2 名の場合: 4 通りの組み合わせを評価
   - 1 名 ×1 名の場合: 1 通りのみ（評価不要）
4. 最適なパターンを選択、未使用候補は usedInRound から削除して次コートで再利用

### スコアリング重み付け

| 評価項目       | 重み    | 適用場面                               |
| -------------- | ------- | -------------------------------------- |
| 出場回数       | 100 点  | 主役選択時のソート                     |
| ペア履歴       | 50 点   | 全選択・評価場面                       |
| 対戦履歴       | 10 点   | 対戦主役パターン評価・ペアパターン評価 |
| 対戦履歴       | 5 点    | ペア候補選択時                         |
| 出場回数       | 10 点   | ペア候補選択時                         |
| プレイヤー番号 | 0.01 点 | タイブレーカー（全場面）               |

## 💻 使い方

1. コート数を選択（1 ～ 3）
   - コート数を変更すると、自動的に最小人数（コート数 ×4 名）が選択されます
2. 参加人数を選択
   - 最小人数: コート数 ×4 名（1 コート=4 名、2 コート=8 名、3 コート=12 名）
   - 最大人数: 30 名
3. 参加者名を入力（任意・改行区切り）
   - 省略時は「プレイヤー 1, 2, 3...」と表示
   - 入力人数と選択人数が異なる場合は警告が表示されます
4. 「ローテーション表を生成」をクリック
5. 統計情報で公平性を確認
6. 必要に応じて画像保存

## ⚠️ 注意事項

- ダブルス専用（シングルス機能は削除済み）
- 最小人数: コート数 ×4 名（1 コート=4 名、2 コート=8 名、3 コート=12 名）
- 最大人数: 30 名
- 少人数（4 名）の場合、ペアの組み合わせパターン評価は 1 通りのみになります
- 背景画像は外部 API（Nekos.best）に依存（オフライン時は表示されません）
