# テニス ローテーション表ジェネレーター 🎾

テニスの試合のローテーション表を自動生成する Web アプリです。シングルス・ダブルス対応、公平な対戦・ペア組みを実現します。

## ✨ 特徴

- 🎨 可愛いパステルデザイン
- 📱 スマホ対応
- ⚖️ 公平なローテーション（出場回数・対戦相手・ペアを均等に分配）
- 📊 統計表示機能
- 💾 PNG 画像保存
- 🔒 完全クライアントサイド実行（データ送信なし）

## 🚀 デモ

`https://[ユーザー名].github.io/[リポジトリ名]/`

## 📦 GitHub Pages 公開手順

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/[ユーザー名]/[リポジトリ名].git
git push -u origin main
```

GitHub リポジトリの `Settings` > `Pages` で `main` ブランチを選択して保存。

## 💻 使い方

1. 試合形式を選択（シングルス/ダブルス）
2. コート数・参加人数を選択
3. 参加者名を入力（任意）
4. 「ローテーション表を生成」をクリック
5. 画像保存も可能

## 📁 ファイル

- `index.html` - メインファイル（HTML + CSS + JavaScript）
- `README.md` - このファイル
