# テニス ダブルス ローテーション表ジェネレーター 🎾

テニスのダブルス試合のローテーション表を自動生成する Web アプリです。高度な公平性アルゴリズムにより、出場回数・対戦相手・ペア組みを最適化します。

## ✨ 特徴

- 🎨 可愛いパステルデザイン + Nekos.best API 背景画像
- 📱 スマホ対応（iPhone 11 検証済み）
- ⚖️ **高度な公平性アルゴリズム**
  - 段階的プレイヤー選択（主役 → 対戦主役 → ペア）
  - 4 パターン評価による最適マッチング
  - 出場回数・対戦履歴・ペア履歴を総合評価
- 🎯 複数コート対応（1 ～ 3 コート以上）
- 📊 統計表示機能（出場回数・ペア回数・対戦回数）
- 💾 PNG 画像保存
- 🔍 デバッグログ出力（開発者ツールで確認可能）
- 🔒 完全クライアントサイド実行（データ送信なし）

## 🧮 公平性アルゴリズム

### ローテーション生成ロジック

**ステップ 1: 主役プレイヤー選択**

- コート数分の主役プレイヤーを出場回数の少ない順に選択

**ステップ 2: 対戦主役プレイヤー選択**

- 各主役の対戦相手を選択
- 評価基準: 対戦履歴（1 点）+ ペア履歴（50 点）
- 既選択の全主役プレイヤーとの関係を総合評価

**ステップ 3: ペアプレイヤー選択**

1. 各主役に対してペア候補を交互に選択（計 4 名）
   - lead1 の 1 人目を選択 → usedInRound に追加
   - lead2 の 1 人目を選択 → usedInRound に追加
   - lead1 の 2 人目を選択 → usedInRound に追加
   - lead2 の 2 人目を選択 → usedInRound に追加
   - 評価: ペア履歴 50 点 + 対戦履歴 5 点 + 出場回数 10 点 + プレイヤー番号 0.01 点
2. 4 名から 4 通りの組み合わせパターンを生成
3. 各パターンを評価（ペア履歴 50 点 + 対戦履歴 10 点）
4. 最適なパターンを選択、未使用候補は次コートで再利用

### スコアリング重み付け

| 評価項目       | 重み    | 適用場面                   |
| -------------- | ------- | -------------------------- |
| 出場回数       | 100 点  | 主役選択時のソート         |
| ペア履歴       | 50 点   | ペア候補選択・対戦主役選択 |
| 対戦履歴       | 10 点   | パターン評価時             |
| 対戦履歴       | 5 点    | ペア候補選択時             |
| 出場回数       | 10 点   | ペア候補選択時             |
| プレイヤー番号 | 0.01 点 | タイブレーカー（全場面）   |

## 💻 使い方

1. コート数を選択（1 ～ 3）
2. 参加人数を選択（4 ～ 16 人）
3. 参加者名を入力（任意・改行区切り）
   - 省略時は「プレイヤー 1, 2, 3...」と表示
4. 「ローテーション表を生成」をクリック
5. 統計情報で公平性を確認
6. 必要に応じて画像保存
